# Мой помощник: приложение для бабушки

Простое приложение для Android: крупные кнопки, светлые цвета, без рекламы и без сообщений.

**6 кнопок на главном экране:** Позвонить · Напоминания · Игры и память · Фото семьи · Слушать · Полезное.
Внизу всегда красная кнопка «Позвать на помощь».

## Как получить .apk
1. Откройте вкладку **Actions** → «Собрать APK». Сборка идёт 5–10 минут (если не началась сама, нажмите Run workflow).
2. Когда появится зелёная галочка, откройте запуск и внизу, в разделе **Artifacts**, скачайте `moy-pomoshnik-apk`. Внутри `app-debug.apk`.
3. Передайте файл на телефон, откройте его и разрешите установку из этого источника.

## Первая настройка на телефоне
Откройте приложение, разрешите уведомления. Внизу главного экрана нажмите «Для семьи»: добавьте номера родных, выберите, кому звонить при вызове помощи, настройте размер текста. Фото и записи для прослушивания добавляются в разделах «Фото семьи» и «Слушать».

Кнопка «Позвонить» открывает набор номера, остаётся нажать зелёную трубку. Всё хранится только в телефоне.
